📲 V9 · Deploy & Install

V9 disiapkan untuk dipublikasikan sebagai web app dan dipasang di layar utama HP. Untuk instalasi PWA, aplikasi perlu dihosting melalui HTTPS.

Privasi: V9 masih menyimpan proyek di browser perangkat. Saat pindah HP/browser, ekspor backup JSON. Jangan gunakan API key di file yang dipublikasikan; koneksi API publik harus melalui backend aman.

🌐 Workflow Google Flow

1
Siapkan frame gambar

Salin image prompt scene pertama, generate gambar sebagai referensi. Pastikan ciri karakter dan wardrobe sama.

2
Masukkan ke Flow

Buka Google Flow, pilih proyek, gunakan gambar referensi jika workflow mendukung.

Buka Google Flow ↗
3
Generate video per scene

Salin video prompt. Generate klip satu per satu dengan durasi sesuai storyboard. Periksa gerakan dan kontinuitas.

4
Unduh dan edit

Unduh hasil klip, susun di editor video, tambahkan voice-over, musik, subtitle, dan CTA.

Flow tetap merupakan layanan terpisah. Prototipe ini mengatur prompt dan alur kerja; belum mengendalikan Flow secara otomatis.
